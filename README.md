# welcome to my galaxy

this is my little nook of the internet!
click the stars to find out more about me, who i am, and what i like!
(you'd never guess it, but i kind of like 4-point stars)

*It does take a second to load the background, so have a bit of patience witht hat please!*

this website was made using entirely html and css. it includes the star graphic and background edited on canva (i love canva so much) and uses custom fonts (braven, qanect, and theatrical) which i thought represented me best, and some of my favorite star-related quotes, which you'll see in the footers.

i hope you enjoy exploring my page!
